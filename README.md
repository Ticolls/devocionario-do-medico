# Devocionário do Médico

Página de suporte e política de privacidade do app **Devocionário do Médico**: orações católicas para estudantes de
Medicina, gratuito e 100% offline, para iPhone e Android.

- Suporte: https://ticolls.github.io/devocionario-do-medico/
- Política de privacidade: https://ticolls.github.io/devocionario-do-medico/privacidade/

O app não coleta dados nem usa internet.

## Contato

Para relatar um erro ou sugerir algo, abra uma [issue](https://github.com/Ticolls/devocionario-do-medico/issues).

## Sobre este repositório

Site estático publicado pelo GitHub Pages (branch `main`, raiz):

```
index.html              página de suporte
privacidade/index.html  política de privacidade
style.css               estilos
```

O código do app e o catálogo de orações ficam em outro repositório, privado.
